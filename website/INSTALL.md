# O‘rnatish

Asosiy, sozlashsiz foydalanish yo‘li repozitoriy ildizidagi [README](../README.md)da.

Node.js 24+ o‘rnatilgach:

```bash
npm start
```

Bu buyruq ildizdan ham, `website/` ichidan ham ishlaydi. Oddiy rejim uchun `npm install`, Python, `.env`, bulut va API kaliti kerak emas. Ma’lumotlar `website/.local-data/` ichida avtomatik saqlanadi.

To‘liq server arxitekturasi va akkaunt rejimi `website/README.md`da. Shaxsiy joylangan saytda D1 hamda platforma autentifikatsiyasi ishlaydi; bu xizmatlar GitHub kloniga avtomatik ulanmaydi.
